# Code of Conduct

The aim of this document is to foster an open, welcoming, and harassment-free environment
that enables effective co-development of this project by any interested persons. "You" and
"your" in the following text is a reference to that person.

## Encouraged Behaviors

Dedication to the following behaviors, in actions and in principle, is endorsed by this Code of Conduct.

### At All Times

- Being respectful of differing viewpoints and experiences
- Gracefully giving and accepting constructive feedback

### In Comments, Forms, and Files

- Improving, rather than superseding, existing issues, pull requests, and files
- Testing your changes before requesting reviews
- Detecting and following exisiting patterns and coding-style
- Making focussed, modularized contributions

### Using Artificial Intelligence (AI)

- Responsibly using productivity tools to avoide the waste of natural resources
- Acknowledging AI involvement in all relvant commit messages with "Co-authored-by"

## Restricted Behaviors

Instances, threats, and promotion of the following behaviors are violations of this Code of Conduct.

- Spamming or excessive communications
- Too many contributions in a short time frame
- Disrespectful language or harassment
- Submitting (or allowing a tool to submit) issues or pull requests without your review

## Scope

This Code of Conduct applies within all community spaces, and also applies when an individual is officially representing the community in public or other spaces.
