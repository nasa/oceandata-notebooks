## Summary
Two Level-2 (L2) processing suites are available for PACE-SPEXone data: 
1) PACE_SPEXONE_L2_MAPOL_OCEAN 
2) PACE_SPEXONE_L2_AER_RTAPOCEAN and PACE_SPEXONE_L2_AER_RTAPLAND

'MAPOL' is short for [FastMAPOL](https://oceandata.sci.gsfc.nasa.gov/files/atbd/atbd-obdaac-aerosol-ocean-land-FastMAPOL.pdf) (Fast Multi-Angle Polarimetric Ocean and Land), an algorithm that jointly retrieves aerosol and ocean properties. <br>
'RTAP' is short for [RemoTAP](https://oceandata.sci.gsfc.nasa.gov/files/atbd/atbd-obdaac-aerosol-from-RemoTAP.pdf) (Remote Sensing of Trace Gases and Aerosol Products), an algorithm that jointly retrieves aerosol and land-surface properties, with seperate configurations for ocean and land scenes. 

This tutorial introduces the SPEXone L2 aerosol products generated by both algorithms and demonstrates how to access, visualize, and evaluate their retrieved aerosol properties. Following the approach used in the HARP2 tutorials, we will examine a scene associated with the 2025 Los Angeles wildfires, which captured both smoke and dust events. Because of SPEXone's relatively narrow swath, this tutorial will focus primarily on the dust event.

Through this case study, we will explore aerosol optical thickness (AOT), aerosol absorption, and aerosol particle size information to investigate the characteristics of the observed aerosol plume and compare the available retrieval products.

## Learning Objectives
By the end of this notebook, you will understand:

- Acquire and read SPEXone L2 data products from both processing suites.
- Identify and describe the aerosol products available from FastMAPOL and RemoTAP.
- Visualize and interpret key aerosol properties, including AOT, aerosol absorption, and particle size.
- Assess retrieval quality using available data quality indicators and flags.
- Compare aerosol retrievals from the two processing algorithms.

The RemoTAP product contains a larger number of data variables than the FastMAPOL product, reflecting the distinct retrieval approaches and output structures of the two algorithms. RemoTAP provides a more extensive collection of aerosol microphysical properties, including mode-specific parameters, uncertainty estimates, and intermediate retrieval diagnostics. FastMAPOL provides a more focused set of aerosol and ocean color products, together with retrieval diagnostics and angular and spectral remote sensing reflectance.

In both FastMAPOL and RemoTAP, the `wavelength` dimension represents the 34 spectral bands used in the retrievals. FastMAPOL reports all wavelength-dependent variables at these 34 measured bands. In contrast, RemoTAP reports wavelength-dependent variables using the `wavelength3d` dimension at 18 spectral bands. This allows RemoTAP to estimate aerosol properties at additional wavelengths based on predefined aerosol components and their assumed spectral dependencies in complex refractive index.

## 4. Visualize FastMAPOL and RemoTAP aerosol properties

Let's define a function that will generate a map and histogram of a selected variable.

```{code-cell} ipython3
def plot_l2_product(
    lon,
    lat,
    data,
    label,
    title="",
    plot_range=None,
    vmin=None,
    vmax=None,
    figsize=(10, 4),
    cmap="viridis",
    log_scale=False,
    land_color="#f2efe9",
    ocean_color="#dbe9f6",
):
    """Make map + histogram with optional log color scaling and land/ocean background.

    Notes:
      - Assumes lon/lat are 2D or 1D arrays available in the outer scope
        (or change signature to pass them in).
      - For log_scale=True, only positive values are used for autoscaling and histogram.
    """

    valid_geo = np.isfinite(data) & np.isfinite(lon) & np.isfinite(lat)

    masked_data = data.where(valid_geo)

    valid = masked_data.where(masked_data > 0, drop=True) if log_scale else masked_data

    if valid.count().item() == 0:
        raise ValueError("No valid values in data.")

    if vmin is None:
        vmin = valid.quantile(0.02, skipna=True).item()

    if vmax is None:
        vmax = valid.quantile(0.98, skipna=True).item()

    if vmin >= vmax or (log_scale and vmin <= 0):
        vmin = valid.min(skipna=True).item()
        vmax = valid.max(skipna=True).item()

    if plot_range is None:
        plot_range = [
            lon.where(valid_geo).min(skipna=True).item(),
            lon.where(valid_geo).max(skipna=True).item(),
            lat.where(valid_geo).min(skipna=True).item(),
            lat.where(valid_geo).max(skipna=True).item(),
        ]

    fig = plt.figure(figsize=figsize)
    gs = gridspec.GridSpec(16, 60, figure=fig, wspace=1.5)
    ax_map = fig.add_subplot(gs[:, :25], projection=ccrs.PlateCarree())
    ax_cbar = fig.add_subplot(gs[:, 22:24])
    ax_hist = fig.add_subplot(gs[:, 35:])

    ax_map.set_extent(plot_range, crs=ccrs.PlateCarree())
    ax_map.add_feature(cfeature.OCEAN, facecolor=ocean_color, zorder=0)
    ax_map.add_feature(cfeature.LAND, facecolor=land_color, zorder=1)
    ax_map.coastlines(resolution="110m", color="black", linewidth=0.8)
    ax_map.gridlines(draw_labels={"bottom": "x", "left": "y"})

    norm = LogNorm(vmin=vmin, vmax=vmax) if log_scale else None

    pm = ax_map.pcolormesh(
        lon,
        lat,
        masked_data,
        norm=norm,
        vmin=None if log_scale else vmin,
        vmax=None if log_scale else vmax,
        transform=ccrs.PlateCarree(),
        cmap=cmap,
        zorder=2,
    )

    cbar = plt.colorbar(pm, cax=ax_cbar, orientation="vertical", pad=0.2)
    cbar.set_label(label)

    ax_map.set_title(title, fontsize=12)

    ax_hist.hist(
        valid.values.flatten(),
        bins=40,
        range=[vmin, vmax] if not log_scale else None,
        color="gray",
        edgecolor="black",
    )

    if log_scale:
        ax_hist.set_xscale("log")

    ax_hist.set_xlabel(label)
    ax_hist.set_ylabel("Count")
    ax_hist.set_title(f"N={valid.count().item()}")

    plt.show()
```

## 6. Retrieval quality assessment

Both FastMAPOL and RemoTAP use an optimal estimation approach that minimizes a $\chi^2$ cost function to quantify the agreement between measured signals ($m$) and their corresponding forward-model fit ($f$), normalized by the total measurement uncertainties ($\sigma$):

$\chi^2 = \frac{1}{N} \sum (f - m)^2/\sigma^2$

where $N$ is the total number of measurements included in the retreival. 

Both algorithms adaptively assess the quality of the forward-model fit, allowing measurements that are poorly reproduced by the model to be excluded from the retrieval. Consequently, both $\chi^2$ and $N$ provide useful indicators of retrieval performance. Lower $\chi^2$ values indicate better agreement between measurements and the forward-model simulations, while higher $N$ values indicate that more measurements were retained in the retrieval. Thus, retrievals with lower $\chi^2$ and higher $N$ generally indicate better retrieval performance.

Let's map `chi2` and exmaine the distributions of its values:


The $\chi^2$  distributions are generally well behaved, with peaks between 0.5 and 1, indicating good agreement between measurements and the forward-model simulations for most pixels. However, some pixels exhibit substantially higher $\chi^2$ values, suggesting poorer retrieval performance. These pixels can be excluded from subsequent analyses to minimize the influence of lower-quality retrievals.

Both algorithms provide a `quality_flag` variable to characterize retrieval quality. These flags are based primarily on $\chi^2$, the number of retained reflectance $N_{ref}$, and the number of retained degree-of-linear-polarization measurements $N_{DoLP}$. However, the flag definitions differ between the two algorithms:

**FastMAPOL L2 quality flags**

The FastMAPOL `quality_flag` is assigned based on the following criteria:

- quality_flag = 0: $\chi^2<1.5$, $N_{ref}>160$, and $N_{DoLP}>160$
- quality_flag = 1: when $\chi^2<1.5$,  $N_{ref}>140$, and $N_{DoLP}>140$
- quality_flag = 2: $\chi^2<2$, $N_{ref}>140$, and $N_{DoLP}>140$
- quality_flag = 3: $\chi^2<2$,  $N_{ref}>100$, and $N_{DoLP}>100$
- quality_flag > 4: indicates progessively poorer retrieval quality, associated with higher $\chi^2$ and/or fewer retained measurements ($N_{ref}$ and $N_{DoLP}$)

**RemoTAP L2 quality flags**

RemoTAP uses a different flagging scheme, with `quality_flag` representing specific retrieval or spatial conditions: 

- quality_flag = 0: good.
- quality_flag = 1: large chi2.
- quality_flag = 2: land-water adjacent.
- quality_flag = 3: cloud adjacent.
- quality_flag = 12: large chi2, land-water adjacent.
- quality_flag = 13: large chi2, cloud adjacent.
- quality_flag = 23: land-water adjacent, cloud adjacent.
- quality_flag = 123: large chi2, land-water adjacent, cloud adjacent

Specifically, the criteria for quality flag 0 and 1:
- quality_flag = 0: $\chi^2<5$ over land and $\chi^2<10$ over ocean, not land-water-adjacent, not cloud-adjacent
- quality_flag = 1: $\chi^2 \ge 5$ over land and $\chi^2 \ge 10$ over ocean

**Note:** Because FastMAPOL and RemoTAP use different quality flag definitions and thresholds, their flag values should not be interpreted as directly equivalent. Consider these differences when comparing retrieval quality between the two algorithms.

## 7. Adaptive Data Screening (FastMAPOL)

+++

The FastMAPOL algorithm applies adaptive data screening at each SPEXone viewing angle. These adaptive data masks provide an additional means of evaluating retrieval performance and measurement quality across viewing angles. The `mask_ref` variable identifies measurements screened based on normalized reflectance, while `mask_dolp` identifies measurements screened based on the degree of linear polarization (DoLP).

A value of 0 indicates that a measurement was retained and used in the retrieval, whereas a value of 1 or NaN indicates that the measurement was excluded.

The plots below highlight differences in the spatial patterns of the reflectance and DoLP masks. These differences may provide insight into variations in the quality and calibration performance of the reflectance and polarization measurements.

```{code-cell} ipython3
angle_index = 0
wavelength_index = 7
```
