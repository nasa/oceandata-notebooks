## Summary

SeaHawk-HawkEye was a CubeSat mission designed to provide high-quality ocean color observations for monitoring marine ecosystems and inland and coastal waters. Developed through the Sustained Ocean Color Observations using Nanosatellites (SOCON) program, funded by the Gordon and Betty Moore Foundation and managed by the University of North Carolina Wilmington, HawkEye demonstrated that a compact 1U CubeSat (10 × 10 × 10 cm) could produce scientifically valuable ocean color measurements. The instrument collected imagery in eight spectral bands at a spatial resolution of approximately 120 m, with each scene consisting of roughly 1,800 × 6,000 pixels.

This tutorial demonstrates how to discover, access, and visualize SeaHawk-HawkEye Level-2 Ocean Color data using Python and the `earthaccess` package. Level-2 products are atmospherically corrected geophysical data generated by NASA's Ocean Biology Processing Group (OBPG).

Throughout the tutorial, you will learn how to authenticate with NASA Earthdata, search for data using temporal, spatial, and cloud cover filters, open Level-2 products with `xarray` datatrees, and visualize ocean color variables on geographic maps. These skills provide a foundation for exploring HawkEye observations and integrating them into ocean color research workflows.

## Learning Objectives

```{code-cell} ipython3
    keyword="SeaHawk"
    )

for item in results:
    summary = item.summary()
    print(summary["short-name"])
```

The three collections with SeaHawk/HawkEye are 
1. `HAWKEYE_L2_OC` : HawkEye Level 2 products generated by NASA OBPG L2gen
2. `HAWKEYE_L1` : HawkEye Level 1 products (not atmospherically corrected)
3. `SEAHAWK_VALIDATION` : In situ data collected to validate HawkEye products

We will be using HawkEye Level-2 products in this tutorial.

+++

### Filter data
The following three options can be specified to filter the data collection using `earthaccess`.
1. `tspan` : Specify date range
2. `bbox`  : Specify spatial extent in decimal degrees
3. `clouds` : Specify cloud cover extent allowed.

```{code-cell} ipython3
tspan = ("2022-11-28", "2024-03-20")
bbox = (-82.75, 30.25, -80.74, 33.25)
clouds = (0, 75)
```

```{code-cell} ipython3
results_scenes = earthaccess.search_data(
    short_name="HAWKEYE_L2_OC",
    temporal=tspan,
    bounding_box=bbox,
    cloud_cover=clouds,
    )
len(results_scenes)
```

## 5. Visualize Hackeye data
#### Load the `Rrs447` variable for visualization

```{code-cell} ipython3
datatree = xr.open_datatree(paths[0])
rrs_447 = datatree["geophysical_data"]["Rrs_447"]
rrs_447
```

#### Obtain coordinates from navigation data group and store them along with `Rrs447`

```{code-cell} ipython3
for item in ("longitude", "latitude"):
    rrs_447[item] = datatree["navigation_data"][item]
rrs_447
```

#### We can now visualize `Rrs447`

```{code-cell} ipython3
plot = rrs_447.plot(x="longitude", y="latitude", cmap="viridis", robust=True)
```

#### Add a projection and add a coastline to the visualization

```{code-cell} ipython3
fig, ax = plt.subplots(subplot_kw={"projection": ccrs.PlateCarree()})
im = rrs_447.plot(x="longitude", y="latitude", cmap="viridis", robust=True, ax=ax)
ax.gridlines(draw_labels={"left": "y", "bottom": "x"})
ax.coastlines()
plt.show()
```
