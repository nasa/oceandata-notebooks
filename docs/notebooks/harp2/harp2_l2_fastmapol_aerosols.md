## Summary
This notebook explores the HARP2 Level-2 (L2) aerosol products generated by FastMAPOL (Fast Multi-Angle Polarimetric Ocean and Land), an algorithm that jointly retrieves aerosol and ocean properties. For more detailed information about the algorithm and data products, please refer to the [FastMAPOL ATBD](https://fastmapol.github.io/mapol-doc/).

We will cover both the MAPOL_OCEAN (aerosol-over-ocean) and MAPOL_LAND (aerosol-over-land) data suites, which we merge to conveniently explore similarities and differences in the two retrievals. It is important to be aware that the current MAPOL_OCEAN product generally shows better retrieval performance than the MAPOL_LAND product. **MAPOL_LAND is still undergoing evaluation and should be used with caution, as the retrievals may exhibit significant biases**. The MAPOL_OCEAN product is recommended for aerosol product evaluation and scientific analysis, preferably using retrievals with a quality flag ≤ 1. It is also recommended to use the most updated version in any analyses, the most current data version is version 4.0 (V4_0).

```{code-cell} ipython3

def plot_l2_product(
    lon,
    lat,
    data,
    label,
    title="",
    plot_range=None,
    vmin=None,
    vmax=None,
    figsize=(10, 4),
    ellipses=[],
    cmap="viridis",
    log_scale=False,
    land_color="#f2efe9",
    ocean_color="#dbe9f6",
):
    """
    Make a map and histogram with optional log color scaling and land/ocean background.

    Args:
        lon, lat - 1D or 2D longitude and latitude arrays
        data - data variable to plot
        label - color bar label
        title - title for the plot
        plot_range - scene extent for the map in [W, E, S, N]
        vmin, vmax - minimum and maximum values to use for plotting
        figsize - size of the plotted figure in (width, height)
        ellipses - a list of dictionaries used to plot an ellipse on the figure to
                   hightlight a region of interest. An example dictionary looks like:
                   {"label": "text", "xy": (-118.5, 31), "width": 3,
                    "height": 8, "angle": 0, "edgecolor": (0.004, 0.451, 0.698)}
        cmap - the colormap to use for the plot
        log_scale - whether to plot the data on a log scale. Default is False. If True,
                    only positive values are used for autoscaling and histogram.
        land_color, ocean_color - matplotlib-acceptable colors for background land/ocean
    """

    valid_geo = np.isfinite(data) & np.isfinite(lon) & np.isfinite(lat)

    masked_data = data.where(valid_geo)

    valid = masked_data.where(masked_data > 0, drop=True) if log_scale else masked_data

    if valid.count().item() == 0:
        raise ValueError("No valid values in data.")

    if vmin is None:
        vmin = valid.quantile(0.02, skipna=True).item()

    if vmax is None:
        vmax = valid.quantile(0.98, skipna=True).item()

    if vmin >= vmax or (log_scale and vmin <= 0):
        vmin = valid.min(skipna=True).item()
        vmax = valid.max(skipna=True).item()

    if plot_range is None:
        plot_range = [
            lon.where(valid_geo).min(skipna=True).item(),
            lon.where(valid_geo).max(skipna=True).item(),
            lat.where(valid_geo).min(skipna=True).item(),
            lat.where(valid_geo).max(skipna=True).item(),
        ]

    fig = plt.figure(figsize=figsize)
    gs = fig.add_gridspec(1, 2, width_ratios=[3, 1], wspace=0.3)
    ax_map = fig.add_subplot(gs[0], projection=ccrs.PlateCarree())
    ax_map.set_extent(plot_range, crs=ccrs.PlateCarree())

    ax_map.add_feature(cfeature.OCEAN, facecolor=ocean_color, zorder=0)
    ax_map.add_feature(cfeature.LAND, facecolor=land_color, zorder=1)

    ax_map.coastlines(resolution="110m", color="black", linewidth=0.8)
    ax_map.gridlines(draw_labels=True)

    norm = LogNorm(vmin=vmin, vmax=vmax) if log_scale else None

    pm = ax_map.pcolormesh(
        lon,
        lat,
        data,
        norm=norm,
        vmin=None if log_scale else vmin,
        vmax=None if log_scale else vmax,
        transform=ccrs.PlateCarree(),
        cmap=cmap,
        zorder=2,
    )

    cbar = plt.colorbar(pm, ax=ax_map, orientation="vertical", pad=0.1)
    cbar.set_label(label)

    ax_map.set_title(title, fontsize=12)

    ax_hist = fig.add_subplot(gs[1])

    ax_hist.hist(
        valid.values.flatten(),
        bins=40,
        range=[vmin, vmax] if not log_scale else None,
        color="gray",
        edgecolor="black",
    )

    if log_scale:
        ax_hist.set_xscale("log")

    ax_hist.set_xlabel(label)
    ax_hist.set_ylabel("Count")
    ax_hist.set_title(f"N={valid.count().item()}")
    
    if ellipses:
        for ellipse in ellipses:
            ell = ax_map.add_patch(
                Ellipse(
                    facecolor=(0, 0, 0, 0), lw=2, zorder=3, linestyle="dashed", **ellipse
                )
            )
            ell.set_path_effects(
                [
                    path_effects.Stroke(linewidth=4, foreground="white"),
                    path_effects.Normal(),
                ]
            )
        ax_map.legend(loc="upper right")

    plt.show()
```

## 3. Visulize HARP2 L2 aerosol properties

In the print out of the dataset, we can see that the L2 HARP2 FastMAPOL product suites includes a long list of data variables. Both MAPOL_OCEAN and MAPOL_LAND include bulk aerosol optical properties and microphysical properties, as well as those for both fine and coarse mode aerosols (identified by the `_fine`/`_coarse` suffix where applicable). 

Since we merged the two suites, let's explore continuous aerosol retrievals regardless of the underlying surface type. From the list above, we will look at three relevant variables: aerosol optical thickness (AOT), aerosol single scattering albedo (SSA), and aerosol fine mode volume fraction (FVF). The shapes of `aot` and `ssa` show us they are 3D variables, corresponding to (row, column, wavelength). HARP2 collects data at wavelengths = `[440.159, 549.465, 664.564, 865.283]`. Note that `fvf` is a 2D variable, as it has no wavelength dependence. 

In this example, we'll visualize the aerosol properties for a scene observed during the LA wild fires, which occured in early 2025. The scene has two visible high AOT events occuring at the same time, which show HARP2's aerosol capabilities well. We can plot these and investigate the properties of each event to better characterize them.

First, let's take a look at the AOT at 550 nm:


## 5. Filter higher-uncertainty, low AOT pixels

+++

Aerosol absorption and microphysics have larger uncertainties when aerosol loading is low. To ensure we're using the highest quality retrievals, we can remove low AOT cases when necessary. With these cases removed, the properties of our two of high AOT events can be seen more clearly. Let's filter SSA and FVF pixels to keep only those with AOT(550) above 0.1, where retrievals have lower uncertainty.

```{code-cell} ipython3
aot_min = 0.1

filtered_ssa = dataset["ssa"].sel(wavelength=wavelength, method="nearest").where(dataset["aot"].sel(wavelength=550, method="nearest") >= aot_min)

filtered_fvf = dataset["fvf"].where(dataset["aot"].sel(wavelength=550, method="nearest") >= aot_min)
```

```{code-cell} ipython3
plot_l2_product(
    dataset["longitude"],
    dataset["latitude"],
    filtered_ssa,
    plot_range=[-125, -95, 15, 36],
    label=f"Filtered SSA: {wavelength:.1f} nm, (AOT 550>{aot_min})",
    vmin=0.7, vmax=1.0,
    ellipses=ellipses,
    cmap="jet",
)

plot_l2_product(
    dataset["longitude"],
    dataset["latitude"],
    filtered_fvf,
    plot_range=[-125, -95, 15, 36],
    label=f"Filtered FVF: {wavelength:.1f} nm, (AOT 550>{aot_min})",
    vmin=0, vmax=1.0,
    ellipses=ellipses,
    cmap="jet",
)
```

The difference in appearance in the filtered maps below versus the unfiltered plots may be hard to see, but the physical meaning of the array values is quite important. Without the surrounding lower quality pixels, we can see how distinct the two events actually are. The aerosols to the north, with low scattering (low SSA, or high absorption) and small particle size (high FVF), are probably smoke from the LA wildfires. The more southern event with more scattering (high SSA, or less absorption) and large particle size (low FVF) likely derives from dust being blown off the coast of Baja California.

## 6. Advanced quality assessment

+++

FastMAPOL uses an optimal estimation approach that minimizes a $\chi^2$ cost function to quantify the agreement between measured signals ($m$) and their corresponding forward-model fit ($f$), normalized by the total measurement uncertainties ($\sigma$). 

$\chi^2 = \frac{1}{N} \sum (f - m)^2/\sigma^2$

where $N$ is the total number of measurements retained in the retrieval, defined as the sum of reflectance and DoLP measurements:

$N$ = $N_{ref}$ +  $N_{dolp}$. 

HARP2 provides measurements at 90 viewing angles for both reflectance and DoLP. Therefore, assuming one measurement of each type per viewing angle, the maximum number of measurements is 180 (90 reflectance + 90 DoLP).

FastMAPOL adaptively assesses the quality of the forward-model fit, allowing measurements that are poorly reproduced by the model to be excluded from the retrieval. Consequently, both $\chi^2$ and $N$ provide useful indicators of retrieval performance. Lower $\chi^2$ values indicate better agreement between measurements and the forward-model simulations, while higher $N$ values indicate that more measurements were retained in the retrieval. Thus, retrievals with lower $\chi^2$ and higher $N$ generally indicate better retrieval performance.

Let's plot $\chi^2$, $N_{ref}$, and $N_{dolp}$ to assess the quality of the retrievals examined in Section 5.

```{code-cell} ipython3
plot_l2_product(
    dataset["longitude"],
    dataset["latitude"],
    dataset["chi2"],
    plot_range=[-125, -95, 15, 36],
    label="Retrieval cost function: χ²",
    vmin=0, vmax=3,
    cmap="jet",
)

plot_l2_product(
    dataset["longitude"],
    dataset["latitude"],
    dataset["nv_ref"],
    plot_range=[-125, -95, 15, 36],
    label="$N_{ref}$",
    vmin=0, vmax=90,

plot_l2_product(
    dataset["longitude"],

    dataset["nv_dolp"],

```

We can also take a look at the averages of these quality indicators, to get a sense of the whole scene:

```{code-cell} ipython3
print("Mean χ²: " + str(np.round(np.nanmean(dataset["chi2"].values), 2)))
print("Mean Nv_ref: " + str(np.round(np.nanmean(dataset["nv_ref"].values), 2)))
print("Mean Nv_dolp: " + str(np.round(np.nanmean(dataset["nv_dolp"].values), 2)))
```

The $\chi^2$ distribution indicates generally reasonable agreement between the measured signals and forward-model simulations, although with some degree of underfitting, with a mean of approximately 1.6. The average number of measurements meeting the good-fit criteria is relatively low: 64 for reflectance and 49 for DoLP. This suggests a potential discrepancy between the forward model and measured observations, which may arise from forward model assumptions or measurement calibrations.

Now that we understand the factors contributing to the quality flagging, let's see how that informs the overall quality flag variable. A quality flag of 0 represents the highest-quality retrievals and is generally associated with lower $\chi^2$ values and a larger number of valid measurements ($N$). Higher quality flag values indicate less stringent criteria, allowing for larger $\chi^2$ and fewer valid measurements. For details, please refer to the [FastMAPOL ATBD Quality Flag section](https://fastmapol.github.io/mapol-doc/chapters/fastmapol_product_quality.html).

```{code-cell} ipython3
cmap = plt.get_cmap("viridis", 5)

plot_l2_product(
    dataset["longitude"],
    dataset["latitude"],
    dataset["quality_flag"],
    plot_range=[-125, -95, 15, 36],
    label="Quality flag value",
    vmin=0, vmax=4,
    cmap=cmap,
)
```

The majority of pixels have a quality flag of 3, indicating that most retrievals meet the moderate-quality criteria.

## 7. Multi-angle data mask for cloud and data screening

+++

The FastMAPOL algorithm conducts internal adaptive data screening on each HARP2 angle. The data masks are provided for both reflectance and DoLP. A value of 0 means the measurements are used in the retrievals, while a value of 1 or `nan` means the measurements were removed from the retrieval. Therefore, the adaptive data mask can be also used to evaluate fitting and measurement quality at each angle. In the example below, please note the different pattern for reflectance and polarization, which may indicate different calibration performance.

```{code-cell} ipython3
angle_index = 5
view_angle = dataset["sensor_view_angle"].isel(number_of_views=angle_index).item()

cmap = plt.get_cmap("viridis", 2)

plot_l2_product(
    dataset["longitude"], 
    dataset["latitude"], 
    dataset["mask_ref"].isel(number_of_views=angle_index, intensity_bands_per_view=0),
    plot_range=[-125, -95, 15, 36],
    label=f"Adaptive data mask on reflectance: \n{view_angle:.1f}° sensor view angle", 
    vmin=0, vmax=1, 
    cmap=cmap
)

plot_l2_product(
    dataset["longitude"], 
    dataset["latitude"], 
    dataset["mask_dolp"].isel(number_of_views=angle_index, polarization_bands_per_view=0),
    plot_range=[-125, -95, 15, 36],
    label=f"Adaptive data mask on DoLP: \n{view_angle:.1f}° sensor view angle", 
    vmin=0, vmax=1, 
    cmap=cmap
)
```

A more quantitative assessment of retrieval uncertainty can be obtained through error propagation ([Gao et al., 2022](https://doi.org/10.5194/amt-15-4859-2022)). This approach is expected to be incorporated into future reprocessings of FastMAPOL L2 products.

<details>
<summary>1. What does the FastMAPOL algorithm retrieve, and what makes it different from a typical aerosol retrieval?</summary>

FastMAPOL is a **joint aerosol and surface retrieval** algorithm. Unlike typical aerosol algorithms that assume ocean properties, FastMAPOL simultaneously retrieves aerosol properties (AOT, SSA, size, etc.) <i>and</i> ocean properties (wind speed, chlorophyll-a, remote sensing reflectance) from HARP2's multi-angle polarimetric measurements.
</details>

<details>
<summary>2. The notebook shows two aerosol events: smoke (high SSA, high FVF) and dust (low SSA, low FVF). What do SSA and FVF tell you about aerosols?</summary>

**SSA (single scattering albedo)** measures absorption: high SSA means less absorbing (like dust), low SSA means more absorbing (like smoke). **FVF (fine mode volume fraction)** measures size: high FVF means small particles (like smoke), low FVF means large particles (like dust).
</details>

<details>
<summary>3. Why filter out low AOT pixels when analyzing aerosol absorption and microphysics?</summary>

Aerosol absorption (SSA) and microphysical properties (size, refractive index) have larger uncertainties when aerosol loading is low. Filtering out pixels with AOT below a threshold (e.g., 0.1) removes cases where the retrieval is less reliable.
</details>

<details>
<summary>4. What do χ² (chi-squared), N<sub>ref</sub>, and N<sub>dolp</sub> tell you about retrieval quality?</summary>

**χ²** measures how well the forward model fits the measurements (lower is better; ideal is ~1). **N<sub>ref</sub>** and **N<sub>dolp</sub>** count how many reflectance and DoLP measurements passed quality checks and were used in the retrieval (higher is better). Good retrievals have low χ² and high N values.
</details>

<details>
<summary>5. HARP2 measures 90 angles across 4 bands (360 total measurements), but the average N<sub>ref</sub> is only 57 and N<sub>dolp</sub> is 41. Why?</summary>

The FastMAPOL algorithm adaptively screens measurements during retrieval. If a measurement doesn't fit the forward model well (due to clouds, calibration issues, or model assumptions), it's removed. The adaptive data masks (`mask_ref` and `mask_dolp`) show which angles were excluded for each pixel.
</details>
