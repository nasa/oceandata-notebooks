## Summary
This notebook explores the HARP2 Level-2 (L2) aerosol products generated by FastMAPOL (Fast Multi-Angle Polarimetric Ocean and Land), a joint aerosol–surface retrieval algorithm. For more detailed information about the algorithm and data products, please refer to the [FastMAPOL ATBD](https://fastmapol.github.io/mapol-doc/).

We will cover both the MAPOL_OCEAN (aerosol-over-ocean) and MAPOL_LAND (aerosol-over-land) data suites, which we merge to conveniently explore similarities and differences in the two retrievals. It is important to be aware that the current MAPOL_OCEAN product generally shows better retrieval performance than the MAPOL_LAND product. **MAPOL_LAND is still undergoing evaluation and should be used with caution, as the retrievals may exhibit significant biases**. The MAPOL_OCEAN product is recommended for aerosol product evaluation and scientific analysis, preferably using retrievals with quality flag ≤ 1. It is also recommended to use the most updated product in any analyses. The most current data version is version 4.0 (V4.0).

```{code-cell} ipython3
def plot_l2_product(
    lon,
    lat,
    data,
    label,
    title="",
    plot_range=None,
    vmin=None, 
    vmax=None,
    figsize=(12, 4),
    ellipses=[],
    cmap="viridis",
    log_scale=False,
    land_color="#f2efe9",
    ocean_color="#dbe9f6",
):
    """
    Make a map and histogram with optional log color scaling and land/ocean background.

    Args:
        lon, lat - 1D or 2D longitude and latitude arrays
        data - data variable to plot
        label - color bar label
        title - title for the plot 
        plot_range - scene extent for the map in [W, E, S, N]
        vmin, vmax - minimum and maximum values to use for plotting
        figsize - size of the plotted figure in (width, height)
        ellipses - a list of dictionaries used to plot an ellipse on the figure to 
                   hightlight a region of interest. An example dictionary looks like:
                   {"label": "text", "xy": (-118.5, 31), "width": 3, 
                    "height": 8, "angle": 0, "edgecolor": (0.004, 0.451, 0.698)}
        cmap - the colormap to use for the plot
        log_scale - whether to plot the data on a log scale. Default is False. If True, 
                    only positive values are used for autoscaling and histogram.
        land_color, ocean_color - matplotlib-acceptable colors for background land/ocean
    """

    # ------------------
    # Determine vmin / vmax if not given
    # ------------------
    valid = data[np.isfinite(data)]
    if valid.size == 0:
        raise ValueError("No finite values in `data`.")

    if log_scale:
        valid = valid[valid > 0]
        if valid.size == 0:
            raise ValueError("log_scale=True but `data` has no positive finite values.")

        if vmin is None:
            vmin = np.percentile(valid, 2)
        if vmax is None:
            vmax = np.percentile(valid, 98)

        # Safety: avoid invalid/degenerate bounds
        if (vmin is None) or (vmax is None) or (vmin <= 0) or (vmin >= vmax):
            vmin = float(np.min(valid))
            vmax = float(np.max(valid))

    else:
        if vmin is None:
            vmin = np.percentile(valid, 2)
        if vmax is None:
            vmax = np.percentile(valid, 98)

        if (vmin is None) or (vmax is None) or (vmin >= vmax):
            vmin = float(np.min(valid))
            vmax = float(np.max(valid))

    # ------------------
    # Figure layout
    # ------------------
    fig = plt.figure(figsize=figsize)
    gs = fig.add_gridspec(1, 2, width_ratios=[3, 1], wspace=0.3)

    # ------------------
    # Map subplot
    # ------------------
    ax_map = fig.add_subplot(gs[0], projection=ccrs.PlateCarree())
    ax_map.set_extent(plot_range, crs=ccrs.PlateCarree())

    # Land / ocean background (behind data)
    ax_map.add_feature(cfeature.OCEAN, facecolor=ocean_color, zorder=0)
    ax_map.add_feature(cfeature.LAND, facecolor=land_color, zorder=1)

    ax_map.coastlines(resolution="110m", color="black", linewidth=0.8)
    ax_map.gridlines(draw_labels=True)

    norm = LogNorm(vmin=vmin, vmax=vmax) if log_scale else None

    pm = ax_map.pcolormesh(
        lon, lat, data,
        norm=norm,
        vmin=None if log_scale else vmin,
        vmax=None if log_scale else vmax,
        transform=ccrs.PlateCarree(),
        cmap=cmap,
        zorder=2
    )

    cbar = plt.colorbar(pm, ax=ax_map, orientation="vertical", pad=0.1)
    cbar.set_label(label)

    ax_map.set_title(title, fontsize=12)

    # ------------------
    # Histogram subplot
    # ------------------
    ax_hist = fig.add_subplot(gs[1])

    hist_data = data[np.isfinite(data)]
    if log_scale:
        hist_data = hist_data[hist_data > 0]
        bins = np.logspace(np.log10(vmin), np.log10(vmax), 40)
        ax_hist.hist(hist_data, bins=bins, color="gray", edgecolor="black")
        ax_hist.set_xscale("log")
    else:
        ax_hist.hist(
            hist_data, bins=40, range=[vmin, vmax],
            color="gray", edgecolor="black"
        )

    ax_hist.set_xlabel(label)
    ax_hist.set_ylabel("Count")
    ax_hist.set_title(f"Histogram: N={hist_data.size}")
    for ellipse in ellipses:
        ell = ax_map.add_patch(Ellipse(facecolor=(0, 0, 0, 0), lw=2, zorder=3, linestyle="dashed", **ellipse))
        ell.set_path_effects([path_effects.Stroke(linewidth=4, foreground='white'), path_effects.Normal()])
    ax_map.legend(loc="upper right")

    plt.show()
```

## 2. Get Level-2 data

+++

HARP2 L2 data is available from NASA Earthdata. The following block retrieves a single HARP2 L2 granule at the time stamp 2025/01/09 20:00:19 UTC from both the MAPOL_LAND and MAPOL_OCEAN data suites. The most recent HARP2 data version, Version 4.0 (V4.0), is specified in the search.

```{code-cell} ipython3
temporal = (
    "2025-01-09T20:00:20",
    "2025-01-09T20:00:21",
)

results_land = earthaccess.search_data(
    short_name="PACE_HARP2_L2_MAPOL_LAND",
    temporal=temporal,
    granule_name="*V4_0*",
    count=1,
)

results_ocean = earthaccess.search_data(
    short_name="PACE_HARP2_L2_MAPOL_OCEAN",
    temporal=temporal,
    granule_name="*V4_0*",
    count=1,
)

if not results_land:
    raise FileNotFoundError("No MAPOL_LAND granule was found.")

if not results_ocean:
    raise FileNotFoundError("No MAPOL_OCEAN granule was found.")
```

The following cell will assess whether you are using cloud resources located in the same region as the data we just found. If not, it will download that data locally. You can change the local download path as necessary.

```{code-cell} ipython3
if earthaccess.__store__.in_region:
    print("Streaming data")
    paths_land = earthaccess.open(results_land)
    paths_ocean = earthaccess.open(results_ocean)
else:
    print("Downloading data")
    paths_land = earthaccess.download(results_land, local_path="./")
    paths_ocean = earthaccess.download(results_ocean, local_path="./")
```

Although we just downloaded two separate HARP2 datasets covering the land and the ocean, we can merge them to create one continuous aerosol field and make working with the data easier. The next cell reads in the two separate data files and combines them with `dataset_land.combine_first()`. That call uses land values first, and fills any gaps with values from the ocean product where available.

```{code-cell} ipython3
datatree_land = xr.open_datatree(paths_land[0])
datatree_ocean = xr.open_datatree(paths_ocean[0])

dataset_land = xr.merge(
    datatree_land.to_dict().values(),
    compat="override",
)

dataset_ocean = xr.merge(
    datatree_ocean.to_dict().values(),
    compat="override",
)

dataset = dataset_land.combine_first(dataset_ocean)
```

## 3. Understanding HARP2 L2 product structure

+++

In the print out of the dataset in the next cell, we can see that the L2 HARP2 FastMAPOL product suites includes a long list of data. Both MAPOL_OCEAN and MAPOL_LAND include bulk aerosol optical properties and microphysical properties, as well as those for both fine and coarse mode aerosols (identified by the `_fine`/`_coarse` suffix where applicable):

Aerosol optical properties:
- Aerosol optical thickness (`aot`, also known as aerosol optical depth or AOD)
- Aerosol single scattering albedo (`ssa`)
- Ångström coefficient (`angstrom_440_870` and `angstrom_440_670`)
- Aerosol fine mode optical depth fraction (`fmf`)
- and more!

Aerosol microphysical properties:
- Aerosol effective radius (`reff`) and variance (`veff`)
- Aerosol refractive index: real part (`mr`), imaginary part (`mi`)
- Aerosol spherical fraction (`sph`)
- Aerosol volume density (`vd`)
- Aerosol fine mode volume fraction (`fvf`)
- Aerosol layer height (`alh`)
- and more!

This tutorial only investigates a handful of these variables, so please explore the rest by clicking the `Data variables` dropdown.

## 4. Visulize HARP2 L2 aerosol properties

From the list above, we will look at three relevant variables: AOT, SSA, and FVF. The shapes of `aot` and `ssa` show us they are 3D variables, corresponding to (row, column, wavelength). HARP2 collects data at wavelengths = `[440.159, 549.465, 664.564, 865.283]`. Note that `fvf` is a 2D variable, as it has no wavelength dependence.

The scene has two visible high AOT events occuring at the same time, which show HARP2's aerosol capabilities well. ## 5. Filter higher-uncertainty, low AOT pixels

+++

Aerosol absorption and microphysics have larger uncertainties when aerosol loading is low. To ensure we're using the highest quality retrievals, we can remove low AOT cases when necessary. With these cases removed, the properties of our two of high AOT events can be seen more clearly. The cells below filter SSA and FVF pixels to keep only those with AOT above 0.1, where retrievals have lower uncertainty.

```{code-cell} ipython3
aot_min = 0.1

filtered_ssa = np.where(
    dataset["aot"].sel(wavelength=wavelength, method="nearest") >= aot_min, 
    dataset["ssa"].sel(wavelength=wavelength, method="nearest"), 
    np.nan
)
filtered_fvf = np.where(
    dataset["aot"].sel(wavelength=wavelength, method="nearest") >= aot_min, 
    dataset["fvf"], 
    np.nan
)
```

The difference in appearance in the filtered maps below versus the unfiltered plots may be hard to see, but the physical meaning of the array values is quite important. Without the surrounding lower quality pixels, we can see how distinct the two events actually are. The aerosols to the north, with low scattering (low SSA, or high absorption) and small particle size (high FVF), are probably smoke from the LA wildfires. The more southern event with more scattering (high SSA, or less absorption) and large particle size (low FVF) probably comes from dust being blown off the coast of Baja California.

## 6. Advanced quality assessment

+++

For a more advanced quality assessment, we can look to how FastMAPOL runs these retrievals. The algorithm is based on optimal estimation, minimizing a $\chi^2$ cost function defined as the difference between measurement (m) and forward model fitting (f), normalized by total uncertainties ($\sigma$). 

$\chi^2 = \frac{1}{N} \sum (f - m)^2/\sigma^2$

Here N is the total number of measurements used in the retrieval. The algorithm also adaptively evaluates fitting performance - if the fit performs poorly, it will be removed from the retrieval process. Therefore, the $\chi^2$ and $N$ can be used to evaluate retrieval performance. Pixels with small $\chi^2$ (good fit) and large $N$ (more pixels that can be fit) will be higher quality. A more quantitative approach based on error propogation can be also used to compute retrieval uncertainty, which will be included in a future product version.

To support Level-3 data processing, quality flags are defined to indicate retrieval quality. A quality flag of **0** represents the highest-quality retrievals, generally associated with lower $\chi^2$ and a larger number of valid measurements ($N_v$). Higher quality flag values correspond to less stringent criteria, allowing larger $\chi^2$ and fewer valid measurements. For details, please refer to the [FastMAPOL ATBD Quality Flag section](https://fastmapol.github.io/mapol-doc/chapters/fastmapol_product_quality.html).

We can plot $\chi^2$ and $N_v$ for both reflectance and the degree of linear polarization (DoLP) to assess the quality of the retrievals examined in Section 5.

This is likely due to forward model assumptions or measurement calibrations.

## 7. Multi-angle data mask for cloud and data screening

+++

As mentioned previously, the FastMAPOL algorithm conducts internal adaptive data screening on each HARP2 angle. The data masks are provided for both reflectance and DoLP. A value of 0 means the measurements are used in the retrievals, while a value of 1 or `nan` means the measurements were removed from the retrieval. Therefore, the adaptive data mask can be also used to evaluate fitting and measurement quality at each angle. In the example below, please note the different pattern for reflectance and polarization, which may indicate different calibration performance.

```{code-cell} ipython3
angle_index = 5
view_angle = dataset["sensor_view_angle"].isel(number_of_views=angle_index).item()

cmap = plt.get_cmap('viridis', 2)

plot_l2_product(
    dataset["longitude"], 
    dataset["latitude"], 
    dataset["mask_ref"].isel(number_of_views=angle_index, intensity_bands_per_view=0).values,
    plot_range=[-125, -95, 15, 36],
    label="mask_ref", 
    title=f"Adaptive data mask on reflectance: {view_angle:.1f}$^\circ$ sensor view angle",
    vmin=0, 
    vmax=1, 
    cmap=cmap
)

plot_l2_product(
    dataset["longitude"], 
    dataset["latitude"], 
    dataset["mask_dolp"].isel(number_of_views=angle_index, polarization_bands_per_view=0).values,
    plot_range=[-125, -95, 15, 36],
    label="mask_dolp", 
    title=f"Adaptive data mask on DoLP: {view_angle:.1f}$^\circ$ sensor view angle",
    vmin=0, 
    vmax=1, 
    cmap=cmap
)
```

Pixel level uncertainty can also be evalated through error propagation, which propagates measurement uncertainty through the Jacobian of the forward model. The estimated uncertainties are discussed in (Gao et al., 2021) for HARP2 and AirHARP, but are currently not included in the HARP2 L2 products.
