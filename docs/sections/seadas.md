# Basics: SeaDAS & OCSSW

Learn to use the SeaDAS (Sea, earth and atmosphere Data Analysis System) processing tools for comprehensive ocean color data analysis. SeaDAS is the official NASA software package that incorporates OCSSW (Ocean Color Science SoftWare), which provides the core computational engine that powers SeaDAS. OCSSW implements standardized algorithms for atmospheric correction, bio-optical retrievals, and data product generation. While SeaDAS offers both a graphical desktop application and runs OCSSW, the command-line interface to OCSSW can installed without SeaDAS for automated processing workflows, making it ideal for batch processing large datasets and integration into custom analysis pipelines.
